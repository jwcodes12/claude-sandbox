# Claude Sandbox

You are working in a mobile-first Claude Code sandbox monorepo.

## Setup
- OCI ARM server (Oracle Linux 9, 2 OCPUs, 12GB RAM)
- Repo: github.com/jwcodes12/claude-sandbox
- Apps live in `apps/*`
- Existing app: `apps/agi-markets` (Next.js 16, TypeScript, Tailwind)
- News app: `apps/tech-radar` (static site generated by an OCI worker)
- Deploy previews may be configured per app on Vercel or Netlify

## Workflow
- Each session runs on a fresh git branch (e.g. session/20260219-1430)
- When done, `ship` commits and pushes everything, triggering the configured preview deploy
- Branches are kept separate so work can be reviewed and merged later

## Purpose
- Personal sandbox for experimenting with web UI ideas, features, and prototypes
- Keep vibecode apps in one GitHub repo instead of creating a repo for every idea
- Optimise for working, shippable results over perfect code
- Keep things simple — this is for exploration, not production

## Monorepo Conventions
- Add each new idea under `apps/<short-name>`
- Keep each app self-contained unless shared code is clearly useful
- Use root npm workspace scripts for orchestration
- Configure hosting per app by pointing Netlify/Vercel at that app directory
- Keep recurring workers deterministic; use Claude/Codex CLI for manual deep research or maintenance, not as a required cron dependency

## Preferences
- Use Next.js App Router conventions
- Tailwind for styling, no extra CSS files
- Don't add tests or documentation unless asked
