# Tech Radar

Static rolling news site generated by an OCI worker. The public site reads generated JSON from `public/data`; it does not fetch RSS, Twitter, or model APIs in the browser.

## Local Commands

```bash
npm install
npm run fetch -w @claude-sandbox/tech-radar
npm run worker:force -w @claude-sandbox/tech-radar
npm run dev -w @claude-sandbox/tech-radar
```

`worker:force` fetches feeds, clusters recent items, writes topic briefs, and builds `public/`.

## Sources

Edit `feeds.yaml`. Twitter feeds are disabled by default because they need your RSS bridge URL:

```bash
export TWITTER_TECH_LIST_RSS="https://..."
```

The default source mix is:

- personal Twitter tech list RSS and optional account RSS bridge
- Hacker News and Lobsters
- arXiv AI/ML/CL/SE
- GitHub Blog and Changelog
- OpenAI, Anthropic, Google DeepMind, Hugging Face
- Simon Willison, Latent Space, Interconnects, LessWrong curated, Zvi
- Techmeme

## Model Use

The worker always produces deterministic fallback briefs. Model generation is opt-in:

```bash
export TECH_RADAR_ENABLE_LLM=1
export TECH_RADAR_MODEL_PROVIDER=anthropic
export ANTHROPIC_API_KEY=...
```

Set `TECH_RADAR_MODEL_PROVIDER=openai` and `OPENAI_API_KEY` to use OpenAI's Responses API path.

## Agent Workflow

Claude Code and Codex CLI are useful for manual/deep research passes, source tuning, and maintenance on the OCI box. They are intentionally not required by the 15-minute cron path.

Export a topic article from `public/data/articles/*.json`, then run:

```bash
AGENT=claude scripts/agent-research.sh public/data/articles/example.json
AGENT=codex scripts/agent-research.sh public/data/articles/example.json
```

The output goes to `research-notes/` by default.

## Deploy

Netlify default:

```bash
NETLIFY_SITE_ID=... NETLIFY_AUTH_TOKEN=... npm run deploy:netlify -w @claude-sandbox/tech-radar
```

Vercel optional:

```bash
VERCEL_TOKEN=... npm run deploy:vercel -w @claude-sandbox/tech-radar
```

## OCI

Use the templates in `../../ops/systemd`:

- `tech-radar.service`
- `tech-radar.timer`
- `tech-radar.env.example`

Install them under the `opc` user with `systemctl --user`.
